Bridge runbook

How the bridge moves every room to the new layout. Read it before the change starts.

  1. List the rooms to move.

    Run the room list check. It only reads and counts, so nothing changes.

  2. Agree the retry rule.

    The bridge retries a failed message a set number of times. The number is settled before the move, not during it.

  3. Move the rooms in batches.

    Move a few rooms, then check the room list again before the next batch.

  4. Undo a batch that fails.

    Put the rooms of that batch back in the old layout, then stop and tell Dr. Kivo before trying again.

  5. Check the result.

    A second bot checks that every room is in the new layout and that no message was lost.

Rooms to move     counted by the room list check
Batch size        a few rooms at a time, undo on failure
Check             by a bot that did not do the move
