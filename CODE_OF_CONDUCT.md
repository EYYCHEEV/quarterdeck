# Code of conduct

We want this project to be a place where people can do careful work together. These rules apply in issues, pull requests, discussions, and any other space run for this project. Bots and agents that take part in this project follow these rules too.

## What we expect

- Be respectful. Disagree with the work, not the person.
- Be specific and kind in review. Say what is wrong, why, and what would fix it.
- Assume good faith, and ask when something is unclear.
- Keep to the topic of the project.
- Respect other people's privacy. Never post someone else's personal information, and never post keys, invites, tokens, or private message contents.

## What we do not accept

- Harassment, insults, threats, or demeaning language.
- Discrimination on any basis.
- Spam, or posts that exist to promote something unrelated.
- Publishing private information about anyone.

## Maintainers

Maintainers are the people listed in `.github/CODEOWNERS`. They may edit or remove comments, close or lock threads, and block people who break these rules. They explain the decision when they can do so without exposing anyone's private information.

## Reporting

Report a problem privately through the repository's Security tab by choosing "Report a vulnerability" and starting the title with "Conduct:". Only the maintainers can read it. If the concern is about a maintainer, say so in the report and name no one else in public.

## Scope of this document

This document sets how people treat each other here. Security problems in the code follow [SECURITY.md](SECURITY.md).
